# Contribuir

Gracias por ayudar a mejorar Face Recognizer.

## Antes de enviar cambios

- Explica el problema o la mejora y mantén los cambios enfocados.
- No incluyas fotos, videos, modelos entrenados, credenciales ni rutas de datos personales.
- Comprueba que `data/`, `models/`, `output/` y los entornos virtuales sigan excluidos de Git.
- Actualiza el README cuando cambien los comandos o el comportamiento visible.
- Para cambios en captura o reconocimiento, describe cómo se comprobó el flujo y las limitaciones restantes.

## Desarrollo local

Instala las dependencias con `python -m pip install -r requirements.txt`. Usa una muestra sintética o datos cuyo uso esté autorizado; nunca adjuntes datos faciales a una incidencia o pull request.

Las contribuciones deben conservar el procesamiento local y evitar subir imágenes o modelos personales a servicios externos.
